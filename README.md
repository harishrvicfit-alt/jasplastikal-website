# JAS PlastikAL — Website Redesign

Premium, responsive redesign for JAS PlastikAL, built with Next.js 16, React 19 and Tailwind CSS 4.

## Included

- Full company offer and core product specifications
- Responsive desktop and mobile layouts
- SEO metadata and local-business structured data
- Optimized local images with `next/image`
- Downloadable 2024 product catalogue
- Direct phone, email and map actions
- Accessibility and reduced-motion support

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
pnpm lint
pnpm build
```

Content and product assets are sourced from the official [JAS PlastikAL website](https://www.jasplastikal.com/) and its 2024 catalogue.
